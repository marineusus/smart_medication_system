# SD 카드 데이터와 일일 처리

모든 데이터 파일은 SD 카드의 루트에 생성됩니다. 파일명은 코드의 대소문자 표기를 따릅니다. 아래 날짜와 값은 형식 설명을 위한 예시입니다.

## 복용 시간

파일: `Morning.txt`, `Noon.txt`, `Evening.txt`

```text
2026-09-01 08:00
2026-09-02 08:05
```

- 한 줄에 `YYYY-MM-DD HH:MM` 형식으로 저장합니다.
- 같은 날짜·시간대의 학습용 기록은 하나만 사용합니다.
- 기준시간 생성 전에는 해당 시간대의 개방 시간을 수집합니다.
- 기준시간 생성 후에는 새로 성공 처리된 개방 시간만 추가합니다.
- 기준시간은 파일에서 읽은 서로 다른 날짜의 마지막 5개 기록을 분 단위로 변환해 정수 평균으로 계산합니다.

## 성공·실패 결과

파일: `Morning_result.txt`, `Noon_result.txt`, `Evening_result.txt`

```text
2026-09-07 SUCCESS
2026-09-08 FAILURE
```

- 한 줄에 `YYYY-MM-DD SUCCESS` 또는 `YYYY-MM-DD FAILURE`를 저장합니다.
- 기존 성공 결과를 실패로 덮어쓰지 않습니다.
- 실패 후 허용 시간 안에서 성공 이벤트가 발생하면 임시 파일로 기존 실패 줄을 제거한 다음 성공을 저장합니다.
- 부팅 시와 일일 확률 갱신 시 파일 내용을 메모리로 다시 읽습니다.

## 기준시간

파일: `baseline.txt`

```text
Morning=08:00
Noon=12:00
Evening=18:00
Created=2026-09-07
```

`Created`는 기준시간을 처음 생성한 날짜입니다. 기준시간을 갱신해도 최초 생성일을 유지합니다. 세 시간대의 기준시간은 최신 값 한 세트로 저장합니다.

## 일일 처리 일정

| 시각 | 동작 |
| --- | --- |
| 00:00 | 세 시간대 모두 데이터가 충분하면 기준시간 생성·갱신, OLED에 5초 표시 |
| 00:01 | 다음 날 기준시간 계산을 위한 실행 플래그 초기화 |
| 00:02 | 전날 결과가 없는 시간대에 실패 결과 저장 |
| 00:03 | 알림 대상 플래그 초기화 |
| 00:04 | 결과 파일 재로딩, 성공 확률 계산, 알림 대상 갱신 |
| 00:05 | 다음 날 확률 계산을 위한 실행 플래그 초기화 |

부팅 시에는 저장된 기준시간을 불러오고 전날의 미기록 결과를 확인한 뒤 현재 성공 확률을 계산합니다. 당일 성공한 시간대의 알림은 해제합니다. 전원이 꺼져 있던 여러 날짜 전체를 소급 처리하는 기능은 구현되어 있지 않습니다.
